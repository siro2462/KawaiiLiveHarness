# Gemma26B Runtimeの短期改善方針（初期案・改訂あり）

**2026-10-14のHarness v5 / α設計を優先する。** 最新の実コード対応と順序は [design_v5_alpha.md](design_v5_alpha.md)。以下は変更前の初期案であり、balanced JSON救出と初期PlanなしTalk抑止はv5では採用しない。旧probeは未実行。準備中のKeyErrorはCPU準備スクリプトの問題で、モデル生成の失敗ではない。

ユーザーの2026-10-14の目標：短期は「事実を守って自然に喋る」、中期は「記憶から話題を自発的に見つけ、必要に応じて会話を始める」。主力候補はGemma 4 26B-A4B。

## 短期の完了基準

- 固定した元Memoryの物、行為、否定、時点、因果関係を維持する。新しい具体的経験や数値を事実として増やさない。
- フィラー、感想、冗談、言い直し、関連する自然な脱線は残す。
- 同じ内容の言い換えと、根拠のある新しい観点を区別する。
- 短い固定診断を通してから連続発話へ進み、全入力・全候補・未再生理由・再生本文を保存して目視する。
- CPU検査やschema成功だけで品質合格としない。既知の問題例への改善と、許容発話への過剰な拒否がないことを両方確認する。

## 調査で確定した出発点

1. Gemma B/改善版は初期Planが不正でTalk未実行。救出器は動くが、memory_idなどの必須キーが欠ける。
2. Plannerはgreedy。形式失敗時にseedだけ変える現行retryは同じ失敗になる。
3. Gemma BCのT4で架空のうなぎ経験をPlanに追加し、T7でS2Bに関連付けて発話。前回Planとfallbackからも誤情報が残る。
4. 正解Plan付きでもTalkが根拠のない具体的枚数を出す。Plannerだけの修正では足りない。
5. 現在の字句検査は架空のうなぎPlanを通す。全ての日本語命題の正しさを保証する仕組みではない。

## 変更する順序と影響範囲（実装前に提示）

### 段階1：Plannerの形式とretry

- この新しいディレクトリへ追加する。既存の学習・モデル・LoRa・旧Runtime・結果・元Memoryは変更しない。
- 4キーの既存schemaとbalanced JSON救出を維持。
- 必須キー、memory_idの型/候補所属、use_memory=false時のnull、flowの2～4要素を短く明示する。
- 形式失敗のretryでは不足キー等の具体的フィードバックを入力へ追加する。生成seedだけを変えるretryにしない。
- 最大2attempt、初期PlanなしのTalk抑止、active/pending/last_validと対応Memory保持は維持する。
- CPUで保存済みの実失敗を回帰検査し、初回valid/invalid、救出、retry入力差、未知ID、不正型を確認する。
- 学習せず、保持したGemma Planner adapterで4つの固定入力の短い実生成を1回確認する。同じ設定の品質目的再実行はしない。

### 段階2：具体的事実の根拠とTalkの自然さ

- 元Memoryを事実の根拠とし、Recent3・前回Plan・自己生成の追加情報を確定事実へ昇格させない。
- 架空のうなぎ、物や方角の交換、数値の追加、過去から現在への変更を別々に検証する。
- Planの方向付けと事実の根拠を区別。形式が正しくても明確な改変があるPlanをlast_validへ入れない。
- Talkの言い間違い、感想、仮定、冗談への過剰拒否と、再生成/空再生の増加を確認する。
- 新しいLLM検証器、会話進捗DB、Active Episode DB、Dの遷移機構は今回新設しない。
- 意味が曖昧なケースを機械的な事実合格へ混ぜない。全再生・未再生本文をrootが確認する。

### 段階3：連続発話

- 段階1/2で原因を分けた後、同じ開始文・Memory・seed・モデル・生成設定で短い連続発話を比較する。
- 条件名だけでなく実Plan/Memory/Recentを照合し、事実保持・自然さ・意味反復・接続を評価する。
- 10分相当等の長さは文字数の模擬。試験実行と品質合格を区別する。

## 中期の段階

短期の発話基盤が安定した後、次を別の試験で進める。

1. 記憶から話せる候補を発見する。
2. 今の会話との関連や、話し始める必要性を判断する。
3. 発話する/待つを選び、割り込みすぎないことを確認する。
4. 選んだ記憶に沿って自然に切り出す。

話題を自発的に選ぶことを、新しい出来事を作る許可にしない。短期の検証が終わる前に中期機能を同時投入しない。
