The recent DB group-of-four test kept a larger metadata-rich representation without those legends. A saved-input investigation also found that a source desire-timing attribute was not forwarded. This is a concrete information-transfer issue worth testing, not proof that prompt length caused the earlier semantic defects.

The new bounded comparison preserves source text, operation sequence and generation conditions. CPU checks prove their arrival in official decoded model inputs and exercise adopted/held history behavior. Better discourse or factual fidelity must be determined from the later full local comparison. Existing semantic omissions, repetition and temporal drift remain open questions; no production adoption.
